# portfolio-kojima

兒島悠飛（Yuto Kojima）のポートフォリオサイト。単一の `index.html`（CSS埋め込み）で構成され、ビルド不要でそのまま公開できます。

## 構成

- `index.html` — 本体（About / IW Square（TA・SRE）/ Research / Works / Creator / Skills）

## 公開方法の例

- GitHub Pages: このリポジトリを GitHub に push し、Settings → Pages で `main` ブランチのルートを指定
- その他静的ホスティング（Vercel / Netlify / Firebase Hosting 等）に `index.html` を配置しても動作します

## 内容の出典

プロジェクト情報は GitHub アカウント [YutoK-JP](https://github.com/YutoK-JP) の公開リポジトリ（README・作成時期・使用言語）と、IWスクエアの公開Scrapbox等の活動記録をもとに作成しています。
